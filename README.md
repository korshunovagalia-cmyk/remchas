# Рем-час — сайт строительно-ремонтной фирмы

Статическая копия сайта [fedor3382.wixsite.com/remchas](https://fedor3382.wixsite.com/remchas):
качественный ремонт квартир и офисов в Санкт-Петербурге.

## Структура

```
index.html      — страница целиком (шапка, hero, услуги, о нас, статистика,
                  проекты, цена, контакты, подвал)
styles.css      — стили, адаптивная вёрстка, мобильное меню
script.js       — мобильное меню, лайтбокс галереи, валидация формы
images/         — все изображения сайта (19 файлов)
```

## Запуск

Открыть `index.html` в браузере или поднять локальный сервер:

```bash
python3 -m http.server 8777
# http://localhost:8777
```

## Заметки

- Форма обратной связи работает только на фронтенде (бэкенд Wix не воспроизводится).
- Шрифт — Montserrat (Google Fonts) как замена Avenir.
- Раздел контактов содержит встроенную карту Google (Наб. Обводного канала, 63).
